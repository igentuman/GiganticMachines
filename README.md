# Gigantic Machines

Gigantic Machines is a Minecraft mod about building huge machines to handle resources on a much bigger scale.

## Planned machines

- **Bedrock Extractor** digs up resources from deep underground.
- **Titanic Crusher** crushes ores and other materials in big batches.
- **Smelting Complex** melts metals for use in the foundry.
- **Modular Foundry** casts molten metals into parts. You can add more sections for more outputs.
- **Biodome** grows crops and trees from plant samples.
- **Replication Bioreactor** uses mob DNA to make mob drops.
- **Hydroelectric Cascade** turns flowing water into power. You can build it in sections across a river.
- **Genome Analyzer** makes and improves the samples used by the Biodome and Bioreactor.
- **Singularity Press** compresses huge amounts of material into a single item.

The idea is to build a full chain: collect resources, process them, cast what you need, and power it all with your own machines. Better samples will help with farming and mob drops.

This is still a work in progress. You can craft and place the machine blocks, but the machines do not work yet.
